# Aggregation Hub 桌面工具界面设计

**日期：** 2026-08-15  
**状态：** 已获用户确认，待实现  
**关联需求：** `FR-DESK-*`、`NFR-UX-*`；本切片仅改变桌面端信息架构与视觉呈现，不宣称 Provider、模型聚合、日志或客户端真实兼容已经实现。

## 1. 背景与目标

当前桌面端只有一个包含大块运行状态卡片的页面，使用英文装饰标题、浅米/绿色主题和大圆角，容易呈现为 AI Demo，而不是供日常配置与维护的本地工具。

本设计将现有可用能力组织为浅色黑白工具界面，参考用户提供的桌面服务列表样式：顶部轻量工具栏、全宽列表行、右侧行内操作和克制反馈。不得复制第三方品牌、图标、文案或具体视觉资产。

## 2. 信息架构

顶部横向导航固定为：

1. 服务（默认页）：显示由现有 `dashboard_status` 提供的 Provider 摘要。
2. 模型：预留模型聚合页面；当前没有可用控制面 API 时只显示诚实的空状态。
3. 客户端配置：复用现有 Local Key 创建能力，显示已知本地地址与一次性展示的 Key。
4. 日志：预留请求/诊断页面；当前没有 API 时只显示诚实的空状态。
5. 设置：显示版本、运行地址以及已有的刷新、启动、重启能力。

运行状态不再占据主内容区域。右上角常驻一个小型状态按钮，仅显示状态点和简短文本；点击后展开受控浮层，显示运行地址、版本、复制地址、刷新和启动/重启动作。

## 3. 可用性与真实能力边界

- 不渲染没有后端支持的“添加服务”“编辑服务”“测试连接”“查看日志”等可点击假按钮。
- Provider 服务页仅呈现从 Desktop Bridge 读取的真实 Provider 摘要。
- 模型、日志的空状态必须说明对应数据尚未接入，不能伪造业务数据。
- Local Key 仍然只在创建成功后一次性展示；不得写入 URL、存储到浏览器存储或记录到日志。
- 启动、重启、刷新、复制地址和复制一次性 Key 保持现有的失败反馈与重复操作防护。

## 4. 视觉系统

### 4.1 色彩

- 应用背景：`#f6f6f4`
- 面板：`#ffffff`
- 主文字：`#171717`
- 次级文字：`#6b6b6b`
- 边框：`#e3e3e0`
- 强边框/焦点：`#1b1b1b`
- 主按钮：`#171717` 背景配白字
- 语义色仅限小范围状态点、错误提示和警告提示；不得使用渐变或大面积彩色背景。

### 4.2 排版与布局

- 顶部工具栏高度约 56px，左侧产品名，中部导航，右侧状态按钮。
- 主内容使用宽度受控的单列区域；服务列表行全宽、紧凑、信息对齐。
- 圆角限制在 6px~8px，避免胶囊化和大圆角卡片感。
- 删除英文 eyebrow、全大写装饰标签和重复的大标题。

### 4.3 交互

- 可点击列表行和按钮使用 `120ms~160ms ease` 的轻微位移、边框和阴影变化。
- Hover 上移不超过 1px；缩放不超过 `1.01`。
- `:focus-visible` 使用清晰的黑色焦点环。
- `prefers-reduced-motion: reduce` 时关闭位移、缩放和过渡。
- 状态浮层支持鼠标、键盘和 Escape 关闭；点击外部关闭。

## 5. 组件边界

- `App`：负责加载 dashboard、全局状态、导航状态和已有 Desktop Bridge 操作。
- `TopBar`：产品名称、页面导航、紧凑状态控制器。
- `StatusMenu`：右上角状态浮层；不直接访问后端，通过 props 调用 App 的操作。
- `ServicePage`：Provider 摘要列表与真实空状态。
- `ModelsPage`、`LogsPage`：明确的未接入空状态。
- `ClientConfigPage`：Local Key 表单、一次性 Key 与复制反馈。
- `SettingsPage`：当前运行时信息和网关控制。
- CSS 保留在现有项目样式入口中，使用语义 class，而不是在 JSX 内堆叠 style 属性。

## 6. 验收标准

1. 页面默认打开“服务”，导航可切换五个中文页面。
2. 顶部不再出现英文装饰标题和渐变。
3. 运行状态默认仅显示为右上角紧凑控件；地址与控制按钮在浮层中可访问。
4. 服务列表有悬停、焦点和键盘可访问反馈，且不出现假业务操作。
5. Local Key 的创建与一次性展示行为保持不变。
6. 窄窗口下顶部导航和页面内容不溢出；减少动态偏好生效。
7. `pnpm --dir apps/desktop typecheck`、`pnpm --dir apps/desktop lint` 和 `pnpm --dir apps/desktop test --run` 通过。

## 7. 非目标

- 本切片不实现 Provider CRUD、模型聚合、上游 Adapter、日志接口、用量、OAuth 或真实 Claude Code/Codex 配置写入。
- 本切片不引入图标库、全局状态库或新的 UI 组件依赖。
- 本切片不改动 Data Plane、SQLite schema、CredentialStore 或安全模型。
